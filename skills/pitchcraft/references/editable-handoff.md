# 图片初稿到可编辑定稿的交接

## 保存一次，后续复用

同一任务维护一份逐页记录即可，可用已有 JSON、Markdown 或表格，不强制另造系统。至少保留：

- 稳定页码、当前 PNG 路径与版本、图片初稿 PPTX。
- 已确认的准确正文、必保数字/名称、来源和证据状态。
- 认可的样页、统一风格与素材源路径。
- 进入转换的页面范围、应转文字、保留为照片/界面内容的区域。
- 当前状态：图片已生成 / 图片已核对 / 用户已认可 / 已回装 / 整页已检查。内部核对不得写成用户认可。
- 已生成的可用干净资产，以及它将替换的页与对象。

不要为每一步重抄正文、重复 OCR 或重新生成参考图。只有源文件或文字变化时更新受影响记录。保存输出后再标记完成，重启时读实际文件验证状态。

## 阶段边界

RW 只负责完整图片稿，在该阶段不创建可编辑布局。后续转换是 Pitchcraft 调用另一个技能的新阶段；图片版的“每页一张图、零原生文字”检查到此结束。转换后分别保存两个版本，禁止将图片版覆盖为编辑版后仍叫“图片稿”。

图片样稿获认可且完整可编辑交付已授权时，无需重复问是否转换。做一张代表性的转换页验证工具和版式，然后继续；用户明确要求转换样张确认时再等。若只能近似恢复关键艺术字、无法保持用户明确要求的像素级特征，说明实际取舍，不把它隐藏在“已完成”后面。

## 转换粒度

- **纯图片稿**：先按整页理解文字与视觉对象，再将正文恢复为原生文本，简单图形按需要原生化，复杂插图作为完整组合素材。不要把整页留作脏底图再加透明文本层；也不要过度切成微小装饰和空白条。首次边界确定后保持稳定。
- **已经拆好的稿件**：读 `image-ppt-to-editable/references/repair-existing.md`，原图片数量、对象位置、大小、裁切、旋转与组织不变。只补缺字和清残字；不能把“整页检查”执行成“合成整页图片”。
- **既有干净分层资产**：直接复用，免去生成和抠图。文本以已确认正文为准，OCR 只定位和核查，不把错识别当原文。

每完成一页或短批次即回装保存并检查。素材生成数不会自动增加完成页数。恢复时优先把现有可用素材用起来，不为追求另一个中间文件格式再生成一次。

## 防止后续修改倒退

| 修改发生时 | 最小动作 |
| --- | --- |
| 图片初稿尚未认可 | 按 RW 修受影响图片页，保留正确正文和其他页面 |
| 图片稿已认可，转换未完成 | 沿用认可页，只修对应清底图或新增文本，不重画页面 |
| 可编辑稿只改一句文案 | 优先改原生文本，验证该页；不自动重生成整套图片 |
| 用户要求两版同步 | 更新受影响的两版页面；不能宣称未更新的初稿与编辑稿文字一致 |
| 用户说完成后不要再改 | 达到约定检查立即另存交付，冻结认可结果 |

默认图片稿保留为转换时的基准。后续修改可编辑版时，在交付中标明图片稿是之前版本；只有用户要求同步两版才承担额外生成成本。

## 典型检查

- 切换阶段后仍要求零文本对象：错误，应改为核对真实可见的可编辑文字。
- 初稿有姓名和数字的准确正文，却再次 OCR 后改错：错误，回到正文和源图。
- 做了很多干净素材但没有可打开页面：先回装再继续。
- 长条素材被生成器加了外部留白：先确认内容边界再尺寸归一，不盲拉伸。
- 不可编辑书法字以轮廓 SVG 保留：属于矢量图形，不能称品牌文字可直接文本编辑。
- 中文在原稿与转换稿的同一渲染器中都成方框：检查字体环境，不把渲染器问题当文件损坏。
