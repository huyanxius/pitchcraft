# 已有可编辑 PPT：保留对象、清底图、补漏字

适用于图片已经拆好，用户只要求去残字、消除重复字、补齐可编辑文字的任务。这里的“整页推进”指工作和验收单位，绝不指把整页压成一张图。

## 1. 先建立源文件基准和真正的问题清单

读取 PPTX 的对象树、媒体关系与文本。记录源文件哈希、页序、画布和每个原图片对象的页码、对象 ID、媒体引用、位置尺寸、裁切、旋转、层级与分组。保留原生文本内容和样式作为比较基准。只提取或处理检查所需的资产，不把媒体总数当工作量。

每一项问题至少能回答：在哪一页、哪个对象、哪段文字；它已存在于文本框还是仅在图片里；对应底图是否需要清理。OCR 与以前的提取稿只用于定位候选，不能成为新文案的事实来源。

先用整页确认清理范围：

- 标题、数据、标签、注释、图注通常应成为可编辑文字；先匹配已有文本的内容与位置，已有一份就不要再加一份。
- 照片里的招牌、衣服标识、真实产品界面或文献原文是否保留，服从用户范围。保留这些内容时，同时从擦除清单和新增文本清单排除，防止半清半留或重复叠字。
- 句子可能跨两张原图片，OCR 也可能把多栏合成一行。先重建逻辑文本和完整坐标，再清除对应残字；图片仍各自保留，文本框可以跨图片边界。
- 人名、网址、数字、书名逐字按源图校对。罗马数字、浅色文字可能漏识别，图标和复选框可能被误识别；不能简单删除所有单字或数字候选。

用户要求先汇报检查结果时，报告具体范围后停在检查；获得继续指令后直接完成已授权工作，不重复问清楚过的要求。

## 2. 先复用，再决定是否需要生成

按“原有干净资产 → 本轮已生成且可用的资产 → 相同材质的现成干净区域 → 必要的新生成”寻找替换内容。恢复被中断的任务时先检查实际文件与回装状态，不从生成队列重新开始。

- 已干净或不在修改范围的对象直接保留。
- 页脚、空白纸纹、简单标题条通常可以复用已验证的干净材质。保留原有细线和装饰，别为每个微小条带单独生成。确有无法复用的复杂背景再生成。
- 需要生成时，编辑**原图片对象对应的资产**，锁定原构图，只去指定文字。新文件仍替换同一个对象；不得把多个对象拼成一张，也不得新增碎片图片去拼原图。
- 干净素材必须真的不含目标文字。把色块或新文本盖在脏图片上，不满足“底层素材干净”。内部修补可用，但输出仍是一份完整清理后的原对象资产。
- 非照片图解可使用已经合格的完整去字结果；真实照片、界面与混合素材优先保留非文字区域的原始内容。局部补丁和整图生成都要检查，不能预设某种方法必然无缝。
- 局部修补发现白块、色差或接缝时，先调整已有结果的取样与区域，或使用已生成的合格整份素材。不要反复生成同一物件，也不能声称生成式重绘像素无损。

图片编辑遵守当前 imagegen 工具要求。裁切、尺寸归一、已有区域复用与组装是确定性处理，不能借此绕过图片编辑约束。

## 3. 生成后立即检查比例并回装

提示词写“相同比例”不保证实际输出比例。宽而矮的资产尤其可能被放进接近常规比例的新画布，出现上下留白。

1. 比较源资产尺寸、生成文件尺寸和实际内容边界。
2. 若确认新增的是外部留白，先去掉留白并对齐内容，再还原原资产像素尺寸。不要直接拉伸整张生成图，否则细线、图标与文字清理区域都会错位。
3. 不盲用居中裁切：只有已经确认内容居中且裁切不会伤及真实内容时才这样做。无法确认时查看原图与结果，而非猜测裁切。
4. 保持 PPT 对象的原有位置、尺寸和裁切参数；正确归一资产后再替换媒体。若同一媒体被多个对象以不同裁切引用，先核对所有引用，避免连带改到未授权区域。
5. 完成一页或一个可及时检查的短批次，立即回装文本与图片、保存可打开的 PPTX，再检查整页。未回装素材开始积压时，先完成回装，不继续扩张生成队列。

不要把“逐个处理”理解成逐张向用户展示工具中间图。用户要看效果时，提供当前完整页面或完整 PPT；不拿残缺条带代替整页成果。

## 4. 补文本和共用透明标志

使用当前 Presentations 技能提供的工具生成新增原生对象。导入导出会改变既有对象时，可将新增对象与必要关系定点写回原 OOXML 包，避免全量重建；维护唯一对象 ID、有效媒体关系和内容类型。不能仅凭组装器成功就宣称原对象完全保留。

- 同时约束文字的实际宽度与高度。OCR 框包含空白，旋转文字的轴对齐外框还包含倾斜带来的高度，不可直接映射成字号。测量真实字形或目标字体，再按原版式拟合。
- 出现宽度不够时先查文字是否识别错、跨栏合并、字体选错或字号过大。不用大幅负字距硬塞；不为修一处溢出缩小整页文字。
- 保留书脊、纸条文字的旋转。前景颜色从字形取样，别误采深色底板而把白字变成深字；检查浅色字、徽章数字与中英混排。
- 只清除经确认属于旧文字遮盖的形状，不误删设计色块、分隔线或真实图形。
- 若要求共用透明标志：优先复用真实 SVG 源，使用一份共享矢量资源并按兼容性提供透明 PNG fallback。保持原图片框；检查透明后露出的背景，以及原标志图里混入的竖线等页面装饰。装饰不能随背景被误删，也不能错误地加入每页共用标志。
- SVG 无不透明背景；PNG fallback 需验证真实 Alpha。文字转轮廓的 SVG 是可缩放矢量，不等于其中品牌文字仍可作为文本编辑，交付时如涉及此需求须区分。

## 5. 检查、进度与停止

批量前先导出一页含中文的源页与输出页，确认渲染器字体正常。两者都出现方框或字体回退时先修字体环境；不要反复改 PPT 来迎合坏的渲染器。原生应用导出超时后选择可验证的替代路径，不反复等待或关闭用户其他文档。

完成检查分两层：

- **结构**：源文件未变；页数、顺序、画布符合要求；逐页图片数量、对象对应、变换、裁切、分组和层级符合基准；原有正确文本与样式保留；新增文本可见可编辑；媒体引用有效；需要透明的资产确实透明。
- **整页内容与版面**：目标残字已清；可编辑文字无遗漏、重复、截断、错别字、拥挤或错色；图片无被压扁、误裁和明显接缝。结构检查和 OCR 都不能代替这一步。使用文件渲染/PDF或原生应用检查，不截图、不上传截图。

首次检查覆盖本次修改页，后续只复查实际修复所影响的页面与共享资产引用页。已有用户认可的页面冻结，不因后续全局脚本重跑而悄悄改变。

进度直接回答“已回装并检查 X/Y 页”，尚未检查的回装页和已生成资产另列；一页只换了标志就说明只换了标志。出现失误后用可打开的当前成果和具体修正回应，不连续道歉、重复承诺或重新索要已给的授权。

全部约定问题修复、必要检查通过、新文件已保存后停止。不要为“更完整”重新生成、重新拆图、增加报告或扩大验收；未能验证的点如实简短说明。

## 决策自检案例

| 遇到的情况 | 应采取的动作 |
| --- | --- |
| 原页两张图片，只有第二张有残字 | 保留两个对象，第一张不动，仅清第二张并补缺失文本 |
| 已生成几十张，但只有两页回装 | 先回装可用结果，报告两页的真实状态，不继续堆生成数 |
| 页脚纯纸纹有字，已有匹配干净纸纹 | 复用并核对细线，不单独生成无意义空白条 |
| 宽条生成后多出上下空白 | 验证内容边界，去新增留白再归一；不直接拉伸、不盲裁 |
| 一行标题跨两张原图片 | 按整页恢复完整文字，分别清两处残字，图片数量不变 |
| 照片内招牌在保留范围 | 不擦招牌，也不额外叠一份可编辑招牌文字 |
| 原版和新版在同一导出器都显示方框 | 先查渲染字体；不以此改原有文本或断言 PPT 损坏 |
| 样张已认可，余页已完成必要检查 | 保留样张和现有成果，另存交付，停止额外修改 |
